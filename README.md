# Mirror

### AIの説明を比べ、根拠と判断を残す。

企業やサービスを調べるとき、AIごとに説明が違う。その違いを質問・確認項目ごとに並べ、保存した公式資料と照合できる比較アプリです。

**個人開発のポートフォリオ / v0.8.1 / local-first**

[アプリを試す](https://mirror-ai-comparison.seyuzau114yuto.chatgpt.site) · [ソースコード](https://github.com/yutoo77/mirror-ai-comparison)

> 最初から架空データで試せます。外部AI APIには接続していません。画面のAI名・回答・判定は実サービスの性能比較ではなく、操作を説明するデモです。持ち込んだ回答の比較・人手レビューにも対応しています。

[3分デモと設計の工夫](docs/PORTFOLIO_STORY.md) · [UI設計](docs/UI_DESIGN.md) · [今後の開発](docs/PRODUCT_DIRECTION.md) · [保存と安全性](docs/PRIVACY.md)

## まず試すこと

1. **比較ラボ**で質問を選ぶ。最大3つの保存回答を同じ確認項目で見比べる。
2. 気になる項目の**根拠を確認**を開く。回答の抜粋・資料の原文・保存時点を確認する。
3. **公式情報**で原文を更新する。変更前の版を残し、関連する確認項目を再確認する。

調査を残す場合は、発見の詳細で理由付きレビューを保存し、監査パックを書き出せます。元のデータを退避する場合は、メニューの「バックアップと復元」を使ってください。

## できることと、まだできないこと

| 実装済み | 未実装・検証前 |
| --- | --- |
| 同じ質問への保存回答の比較・条件表示 | 外部AI APIからの回答取得 |
| 回答の手動取り込みと人による判定 | 意味に基づく自動ファクトチェック |
| 公式原文・更新理由・過去50版の保存 | Webページの自動取得・変更監視 |
| 根拠への参照、理由付きレビュー、調査資料の書き出し | クラウド同期・共同編集・認証 |
| ローカルデモ観測の実行・中止・全ジョブの記録 | 実サービスを対象とする精度・費用評価 |

原文の差分は文字の比較です。公式資料も無条件の正解ではありません。対象プラン・地域・時点などの条件を含めて人が確認するための道具であり、自動で真偽を保証する製品ではありません。

## 設計で工夫したこと

**「分からない」を正常扱いしない。** 言及なし、誤り、引用不足、未評価を分け、質問の対象外の項目を評価の分母へ混ぜません。[指標の定義](docs/METRIC_SPEC.md)

**後から資料が変わっても、昔の判定を壊さない。** 観測時の条件と原文の識別情報を保存し、過去版があれば当時の本文を表示します。なければ現在の本文で埋めず「未収録」と表示します。[版管理](docs/SOURCE_HISTORY.md)

**回答を取る処理に、採点用の正解を渡さない。** 取得と評価を別のインターフェースに分けました。成功した回答だけでなく、失敗・中止も予定したジョブの記録に残します。[実行設計](docs/EXECUTION_PROTOCOL.md)

**機能一覧より、確認する作業を主役にする。** 最初の画面を比較に絞り、全文や理由は必要なときに開きます。デモ、未評価、資料の版など、判断を変える注意は操作のそばに残します。[UIの判断](docs/UI_DESIGN.md)

SHA-256はデータの整合性を確認するための識別情報です。電子署名や、内容・作成者の真正性の証明ではありません。既存製品にない世界初の機能とは主張せず、実装上の判断と検証できる不変条件をこの作品の説明軸にしています。

## ローカルで起動

Node.js 22.12以上と、`packageManager` で指定したpnpmを使います。APIキー・アカウント登録は不要です。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

起動時に表示されるローカルURLを開いてください。

```sh
pnpm check          # 型チェック・Lint・テスト・本番ビルド
pnpm release:check  # 公開対象の禁止ファイル・典型的な秘密情報を点検
pnpm preview        # 本番ビルドをローカルで確認
```

自動テストは、比較の分母、過去の根拠保持、保存失敗、破損データの保護、ファイル互換、キーボード操作などを対象にしています。過去の画面確認と、未実施の実ユーザーテストは [検証記録](docs/UI_DESIGN.md) に区別して記載しています。

2026-09-07の公開用コピーの確認では、型チェック・Lint・22ファイル175テスト・本番ビルドが通過しました。[公開準備の確認範囲](docs/PUBLIC_RELEASE.md)

## 構成

React / TypeScript / Vite / React Router / Zod / Vitest。状態はこのブラウザのlocalStorageに保存します。

```text
画面・入力フォーム
    ↓
WorkspaceProvider ── localStorage / バックアップ
    ↓
domain（比較・版管理・指標・形式検証）
    ↑
execution（計画 → 回答取得 → 評価 → 実行記録）
```

`src/domain` は画面から独立したロジック、`src/execution` は取得と評価の境界、`src/features` は作業別の画面です。大規模な基盤を先に導入せず、個人開発で試せる範囲を優先しています。[設計判断の記録](docs/adr/)

## 次に深めること

サーバー側にAPIキーを置く境界と、予算を制限した実APIアダプターを実装し、少数の実例から評価を始めます。その後、条件の取り違えや根拠不足を未見データで測り、通常の調査方法と比較して有用性を確かめます。自動評価の精度向上や利用者の時間短縮は、現時点の実績としては扱いません。

## 公開範囲とデータ

このリポジトリは汎用モデルと架空データによる独立実装です。以前の組織向けプロトタイプ、企業固有の設定・資料、APIキー、利用者がブラウザに保存した調査内容は含めません。特定企業・AI提供会社の公式サービスではありません。

入力内容はこのアプリから外部AIへ送信されません。ただし、外部リンクを開いた先や配信基盤のアクセスログは別の範囲です。バックアップには原文・回答・履歴が含まれ、暗号化されません。秘密情報を入力・共有しないでください。[データの取り扱い](docs/PRIVACY.md) / [脅威モデル](docs/THREAT_MODEL.md)

AI支援を設計の検討・実装・テスト・文書化に利用しています。AIが生成した案や説明をそのまま成果として扱わず、採用した判断をコードと検証範囲に対応付けて説明する方針です。[作品の説明ガイド](docs/PORTFOLIO_STORY.md)

公開はコード閲覧と作品紹介を目的とします。このリポジトリには、再配布・商用利用を許諾するライセンスは現時点では設定していません。
