# ADR 0001: Clean-room public rebuild

- Status: Accepted
- Date: 2026-09-02

## Context

初期プロトタイプには、特定組織向けの設定、Fixture、提出用資料が含まれていた。ファイルを削除してもGit履歴から復元できるため、同じ履歴を公開できない。

## Decision

公開版は新しいリポジトリとGit履歴で再実装し、架空データと汎用モデルだけを含める。初期版の原本は非公開の比較資料として保持する。

## Consequences

- 公開境界が明確になる
- 汎用化がコード構造から確認できる
- 既存コードの直接コピーを避けるため、短期的な実装量は増える
