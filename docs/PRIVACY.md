# データの取り扱い

対象: Mirror v0.8.1 / 更新: 2026-09-07

## 入力と保存

ワークスペース、原文、AI回答、確認項目、レビューは、利用しているブラウザのlocalStorageに保存します。アカウント、クラウド同期、共同編集はありません。端末・ブラウザ・配信元のURLが変わると、保存内容も別になります。

ブラウザのデータを消すと記録を失う可能性があります。「バックアップと復元」で保存してください。容量不足では画面上に警告しますが、永続保存が保証されるわけではありません。

## 外部との通信

この版には、入力した資料や回答を外部AI・Mirrorのデータ保存サーバーへ送る機能はありません。デモ観測もブラウザ内で実行します。アプリに解析用トラッカーや広告は組み込んでいません。

ただし、アプリ本体を読み込む通信や、配信基盤側の通常のアクセスログは存在し得ます。資料・引用の外部リンクを開くと、そのリンク先と通信します。「通信が一切発生しない」「匿名性を保証する」という意味ではありません。

## ファイルと公開範囲

監査パックとバックアップには、入力した本文、AI回答、更新履歴、レビューなどが含まれます。暗号化・伏せ字・共有権限の制御はありません。共有前に中身を確認してください。

公開ソースには架空の初期データだけを含めます。作成者や他の利用者がブラウザに保存した内容を、サイトの公開時にまとめてアップロードする仕組みはありません。

APIキー、個人情報、契約で制限された資料、非公開の業務データは入力しないでください。localStorageは暗号化保管庫ではなく、同一配信元で動くスクリプトなどからアクセスされ得ます。

## 判定と利用上の限界

画面の判定は保存時点の記録です。デモ回答は架空で、実在するモデルの精度・優劣を示しません。公式資料にも適用条件や時点の制約があります。重要な判断は原文と実際の状況を確認したうえで行ってください。

技術的な保護と未対応の範囲は [脅威モデル](THREAT_MODEL.md)、保存形式は [バックアップ仕様](BACKUP_AND_RECOVERY.md) を参照してください。
